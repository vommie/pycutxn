# PyCut

Program to cut videos into sections and render them with ffmepg.
With the integrated Tagger it is possible to tag and rate the cutted videos into a XnViewMP database.s

## Installation

Tested on Linux Manjaro only.

### Dependencies
* [`mpv.py`](https://github.com/jaseg/python-mpv) `(libs/mpv.py)`
* `pip install ffmpeg-python`
